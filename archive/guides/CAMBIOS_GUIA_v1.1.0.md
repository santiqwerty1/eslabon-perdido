# Registro de cambios de la Guía Maestra 1.1.0

**Fecha:** 5 de agosto de 2026  
**Versión anterior:** 1.0.0  
**Versión activa:** 1.1.0

## Cambio estratégico

La producción deja de comenzar por el recorte hominino de 400.000–40.000 años y pasa a desarrollarse cronológicamente por campañas. La primera campaña cubre Eukaryota → Holozoa. El trabajo hominino se conserva como especificación de destino, conjunto de pruebas y campaña culminante.

## Cambios principales

- Se añadió historial de revisiones y política de migración no destructiva.
- Se añadió el estado de decisión `SUPERSEDIDO`.
- Se definió Eucaria como primera campaña y primer lanzamiento.
- Se incorporó el cono de foco para limitar cada campaña.
- Se separó el núcleo compartido de los módulos de campaña.
- Se reemplazó el primer Reconstrucción completo por una lente científica ligera, conservando el modo completo para campañas posteriores.
- Se definieron siete campañas cronológicas hasta Homininos.
- Se creó una hoja de ruta de 19 fases, de la migración inicial a sistemas transversales futuros.
- Se preservaron paquetes avanzados de geografía, simulación poblacional, tafonomía, Reconstrucción e integración de modos.
- Se amplió el trabajo pospuesto con disparadores explícitos.
- Se añadieron decisiones DEC-033 a DEC-048.
- Se añadieron fixtures futuros para Hominini, denisovanos, especímenes e introgresión.
- Se añadió el Apéndice J con una matriz de preservación completa.

## Preservación comprobada

Los siguientes apéndices permanecen idénticos a la guía 1.0.0:

- Apéndice A: inventario científico profundo.
- Apéndice B: clasificación de primates.
- Apéndice C: inventario fósil y paleoantropológico.
- Apéndice D: advertencias terminológicas.
- Apéndice F: salida estándar por sección.

El Apéndice E se amplió únicamente para incorporar campaña y módulo de juego.
